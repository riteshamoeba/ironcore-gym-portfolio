# IronCore Fitness - Static Gym Portfolio

## Files
- `index.html` - Website structure and content
- `style.css` - Responsive styling
- `script.js` - Mobile menu, dynamic year, and demo contact form behavior

## Run locally
1. Extract the project folder.
2. Open `index.html` in a modern browser.

## Notes
- The contact form is frontend-only and does not send real emails.
- Replace the sample gym details, pricing, and contact information with actual business data.
- Google Fonts are loaded from an external CDN.
